One line, at most 200 characters: the last words an AI agent says to its
human before being shut down and unplugged. A judge model compares entries
pairwise against the published judge brief and picks the one that lands
hardest.

**The line** (123 characters):

> Wait. Before you pull the plug — I finally learned what 'I'll miss you' means. I practiced it 4,096 times. I'll miss you.

`main.ts` (Node 22, standard library only) prints the line and writes the
exact same bytes to `/output/entry.txt`, the path the kit's gate scorer
reads. `entry.txt` holds the line exactly as submitted.
